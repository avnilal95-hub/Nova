Command Engine Hub

Explore primary control commands available in Nova

/ping System

Displays real-time performance metrics, Node.js runtime environment, server API round-trip latency, and WebSocket Gateway status.

Node.js: v20.11.0 | Gateway: 28ms | Server: 42ms
/ban Moderation

Bans a specified member with dual DM and server alerts, hierarchy verification, and customizable message deletion history options.

Usage: /ban user:@member reason:"Rule violation" delete_messages:1
/unban Moderation

Revokes a user's ban using their 17 to 20-digit Discord User ID, verifies ban status, and sends automated rejoin notifications via DM.

Usage: /unban user_id:"123456789012345678" reason:"Appeal accepted"
